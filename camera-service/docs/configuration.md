# Настройка сервиса камер

Все настройки передаются переменными окружения. В Docker их задаёт корневой `docker-compose.yml` по значениям из `.env` ([docs/docker.md](../../docs/docker.md)), при запуске вручную их задают в терминале ([README](../README.md#запуск)).

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SERVICE_TOKEN` | пусто | Общий секрет с сервисом ГИБДД (заголовок `X-Service-Token`). Только латинские буквы и цифры. Без него сервис запускается, но отвечает `503` на защищённые запросы и не может отправлять события |
| `GIBDD_URL` | `http://localhost:8000` | Адрес сервиса ГИБДД без `/api` в конце. Косая черта в конце убирается |
| `CAMERA_INTERVAL_SECONDS` | `60` | Как часто камеры «видят» автомобиль. Минимум 0.1. Для демонстрации поставьте 10 |
| `HOST` | `0.0.0.0` | На каком адресе слушать |
| `PORT` | `9000` | Порт |
| `CAMERAS_FILE` | `app/cameras.json` | Путь к файлу со списком камер |
| `REQUEST_TIMEOUT_SECONDS` | `5` | Сколько ждать ответа сервиса ГИБДД на одну попытку |
| `DELIVERY_ATTEMPTS` | `3` | Сколько раз пробовать отправить событие (минимум 1) |
| `RETRY_DELAY_SECONDS` | `1` | Пауза перед повтором, растёт с номером попытки: 1 с, 2 с, 3 с |
| `ENABLE_MANUAL_DETECTIONS` | `true` | Разрешена ли ручная фиксация `POST /v1/detections`. Значения: `true` или `false` (также `1`, `0`, `yes`, `no`, `on`, `off`) |

Если значение задано неверно (не число, меньше минимума, неизвестное логическое значение), сервис не запускается и пишет в журнал, какая переменная неверна.

## Формат файла камер

`app/cameras.json`:

```json
{
  "cameras": [
    {
      "code": "CAM-08",
      "address": "ул. Московская 106/1",
      "latitude": 58.599,
      "longitude": 49.6547,
      "type": "Мобильная",
      "speed_limit": 60,
      "active": true
    }
  ]
}
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `code` | да | Код камеры. Уникален. По нему сервис ГИБДД находит камеру у себя |
| `address` | да | Адрес установки |
| `latitude`, `longitude` | да | Координаты |
| `type` | нет | Тип камеры |
| `speed_limit` | нет | Ограничение скорости, км/ч |
| `active` | нет (по умолчанию `true`) | Выбирает ли эмиттер эту камеру. Отключённая камера не создаёт событий, ручная фиксация на ней даёт `422` |

**Важно:** набор камер в этом файле должен совпадать с камерами в базе сервиса ГИБДД (`backend/seed.py`, таблица `cameras`): по коду, адресу и координатам. Если камера есть здесь, но нет в базе ГИБДД, события с неё отклоняются (`422`). Тест [test_contract_with_backend.py](../tests/test_contract_with_backend.py) сравнивает оба списка и падает при расхождении.

## Журнал

Сервис пишет в стандартный вывод строки вида:

```
2026-10-12 12:00:00,123 INFO Получен список розыска: 2 ГРЗ
2026-10-12 12:00:10,456 INFO Зафиксирован А123ВК43 на CAM-08: ответ ГИБДД {'status': 'accepted', 'alert_id': 77, 'delivered': True}
2026-10-12 12:00:20,789 WARNING Событие 9f3c… (А123ВК43, CAM-08) не доставлено: не удалось отправить за 3 попыток: …
```

В Docker их показывает `docker compose logs -f camera-service`.
