# Страницы и кнопки

Для каждой страницы: что показывает, какие запросы к backend выполняет и что делает каждая кнопка. Форматы запросов и ответов: [backend/docs/api.md](../../backend/docs/api.md).

## Вход (`/login`)

Название системы, поля «Логин» и «Пароль», кнопка входа.

| Действие | Запрос | Результат |
|---|---|---|
| Кнопка входа | `POST /auth/login` | Успех: сообщение «Добро пожаловать», переход на `/dashboard`. Ошибка: сообщение сервера («Неверный логин или пароль») |

## Меню (на каждой странице после входа)

Слева: Главная, Мой розыск, База розыска, Карта, История, Профиль. Кнопка выхода внизу.

| Кнопка | Что делает |
|---|---|
| Пункты меню | Переход на страницу, активный пункт подсвечен |
| Выход | `POST /simulator/stop`, очистка токена, переход на `/login` |

## Главная (`/dashboard`)

Три счётчика: «В розыске», «Найдено», «Всего» (считаются по `GET /wanted/my`) и список оповещений, на которые не было реакции (`GET /alerts/pending`).

| Кнопка | Запрос | Результат |
|---|---|---|
| Принято | `PUT /alerts/{id}/reaction` (`Принято`) | Оповещение пропадает из списка |
| Отклонить | `PUT /alerts/{id}/reaction` (`Отклонено`) | Оповещение пропадает из списка |

После любой реакции вызывается `POST /simulator/resume`, чтобы симулятор продолжил поиск. Если оповещений нет, показывается «Нет активных оповещений».

## Мой розыск (`/my-wanted`)

Таблица записей текущего сотрудника (`GET /wanted/my`): ГРЗ, модель, цвет, статус, время, дата и адрес последней фиксации.

| Кнопка | Что происходит |
|---|---|
| Добавить в розыск | Открывается диалог, шаг 1: выбор ГРЗ из списка свободных автомобилей (`GET /wanted/available-plates`). Если свободных нет, сообщение «Все автомобили в базе уже находятся в розыске» |
| Далее, Назад | Переход между шагами диалога |
| Шаг 2: выбор причины | Список из `GET /wanted/violation-categories` |
| Добавить | `POST /wanted/add`; запись появляется в таблице |
| Отмена | Закрывает диалог без изменений |
| Удалить из розыска | Нужно сначала выбрать строку (иначе подсказка «Сначала выберите строку в таблице»). Открывается подтверждение |
| Да, Отмена (подтверждение) | `DELETE /wanted/{plate}`; строка исчезает. «Отмена» ничего не удаляет |

Строка выбирается нажатием на неё.

## База розыска (`/all-wanted`)

Таблица всех активных записей всех сотрудников (`GET /wanted/all`): ГРЗ, модель, цвет, сотрудник, статус.

| Кнопка | Когда доступна | Что делает |
|---|---|---|
| Взять себе | Для чужой записи со статусом «В розыске» | Подтверждение, затем `POST /wanted/take/{id}`: розыск передаётся вам, у прежнего сотрудника запись закрывается |

Для своих записей вместо кнопки написано «Это ваш розыск».

## Карта (`/map`)

Карта камер видеофиксации (картинка).

| Кнопка | Что делает |
|---|---|
| Увеличить, Уменьшить | Масштаб карты (с ограничениями), текущий масштаб показан в процентах |
| Сброс | Возврат масштаба к 100% |
| Снять подсветку | Возврат от карты с выделенной камерой к общей. Видна только пока камера подсвечена |

Когда приходит оповещение, карта автоматически показывает картинку `cam_N.png` с красной камерой и баннер «Автомобиль … зафиксирован на камере №N». Подробнее: [alerts-flow.md](alerts-flow.md).

## История (`/history`)

Оповещения текущего сотрудника (`GET /alerts/history?period=...`): дата и время, ГРЗ, адрес, статус.

| Кнопка | Запрос |
|---|---|
| Сегодня | `?period=today` |
| Неделя (по умолчанию) | `?period=week` |
| Месяц | `?period=month` |

Статусы: «Найден», «Принято», «Отклонено», «Ожидает».

## Профиль (`/profile`)

Данные сотрудника из `GET /employees/me`: должность, email, телефон, дата рождения, дата приёма на службу, подразделение. Кнопок нет.

## Окно оповещения

Показывается поверх любой страницы, когда по WebSocket приходит сообщение `detection`: «ВНИМАНИЕ! Обнаружен автомобиль», ГРЗ, место, дата и время.

| Кнопка | Что делает |
|---|---|
| Принято | `PUT /alerts/{id}/reaction` (`Принято`); окно закрывается, через заданный интервал появится вопрос «Автомобиль задержан?». Если запрос не прошёл, окно остаётся открытым и показывается ошибка |
| Да, Нет (вопрос о результате) | `PUT /alerts/{id}/found`; затем `POST /simulator/resume` |
