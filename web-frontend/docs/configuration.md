# Настройка и сборка

## Переменные окружения

Файл `web-frontend/.env` (шаблон: [`.env.example`](../.env.example)) в git не попадает.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `REACT_APP_API_URL` | `http://localhost:8000/api` | Адрес API backend |
| `REACT_APP_WS_URL` | выводится из `REACT_APP_API_URL` | Адрес WebSocket (`ws://host:8000/ws`). Нужен, только если он не совпадает с адресом API |
| `REACT_APP_FOUND_PROMPT_DELAY_MS` | `60000` | Пауза между «Принято» и вопросом «Автомобиль задержан?» |

Как выводится адрес WebSocket: в `REACT_APP_API_URL` схема `http` заменяется на `ws`, окончание `/api` отбрасывается, добавляется `/ws`. Например, `http://192.168.0.15:8000/api` даёт `ws://192.168.0.15:8000/ws`.

Create React App читает переменные **только при запуске** (`npm start`) и при сборке. После изменения `.env` перезапустите сервер разработки. Имена должны начинаться с `REACT_APP_`.

Разбор значений находится в [`src/config.js`](../src/config.js).

## Запуск и сборка

```powershell
npm install          # зависимости, один раз
npm start            # запуск для разработки на http://localhost:3000
npm run build        # сборка для публикации в папку build/
```

Собранную папку `build/` можно отдать любым статическим веб-сервером. Адрес API при этом **зашивается в сборку** на момент `npm run build`, поэтому `REACT_APP_API_URL` задают до сборки.

## Связь с backend

- Backend по умолчанию принимает запросы с любых адресов (CORS открыт), поэтому адрес сайта настраивать на сервере не нужно.
- Если backend запущен на другом компьютере или порту, измените `REACT_APP_API_URL` и перезапустите.
