# Чек-лист ручной проверки

Автоматических тестов у веб-клиента нет, поэтому работоспособность проверяется вручную. Чек-лист проходит по всем страницам и кнопкам. Потребуются запущенные backend и frontend ([README](../README.md)) и тестовый сотрудник из `backend/seed_users.json`.

**Подготовка для быстрой проверки:** `DETECTION_INTERVAL_SECONDS=10` в `backend/.env` и `REACT_APP_FOUND_PROMPT_DELAY_MS=10000` в `web-frontend/.env`.

## Вход

- [ ] Неверный пароль: сообщение «Неверный логин или пароль», остаёмся на `/login`.
- [ ] Верный пароль: сообщение «Добро пожаловать», открывается «Панель управления».
- [ ] Обновить страницу: остаёмся в системе.
- [ ] Открыть `/dashboard` без входа (в приватном окне): перенаправление на `/login`.

## Главная

- [ ] Видны счётчики «В розыске», «Найдено», «Всего».
- [ ] «Принято» и «Отклонить» убирают оповещение из списка (если оно есть).

## Мой розыск

- [ ] «Добавить в розыск» → выбрать ГРЗ → «Далее» → выбрать причину → «Добавить»: строка появилась.
- [ ] «Назад» возвращает на выбор ГРЗ, «Отмена» закрывает диалог.
- [ ] «Удалить из розыска» без выбранной строки: подсказка «Сначала выберите строку в таблице».
- [ ] Выбрать строку → «Удалить из розыска» → «Отмена»: ничего не удалено.
- [ ] Выбрать строку → «Удалить из розыска» → «Да»: строка исчезла.

## База розыска

- [ ] Видны записи всех сотрудников.
- [ ] «Взять себе» у чужой записи: после подтверждения запись помечена как ваша, дубликатов нет (счётчик строк не вырос).

## Оповещение и карта

- [ ] Через 10 секунд после входа (при наличии записей в «Моём розыске») появилось окно «ВНИМАНИЕ! Обнаружен автомобиль».
- [ ] Открылась карта, на ней камера выделена красным, над картой баннер с ГРЗ и адресом.
- [ ] «Принято»: окно закрылось; через заданный интервал появился вопрос «Автомобиль задержан?».
- [ ] «Нет»: вопрос закрылся, через 10 секунд снова приходит оповещение.
- [ ] «Да»: автомобиль получил статус «Найден» и больше оповещений не создаёт.
- [ ] Оставить оповещение без ответа и обновить страницу: оно видно на главной с кнопками «Принято» и «Отклонить», симулятор продолжает работу.
- [ ] Закрыть вкладку сайта, подождать 15 секунд и открыть сайт снова: пропущенное оповещение видно на главной странице.
- [ ] Кнопки масштаба «Увеличить», «Уменьшить», «Сброс» меняют процент.
- [ ] «Снять подсветку» возвращает общую карту.

## История и профиль

- [ ] «Сегодня», «Неделя», «Месяц» перезагружают таблицу; статусы отображаются верно, включая «Отклонено».
- [ ] Профиль показывает должность, email, телефон, даты и подразделение.

## Выход

- [ ] Кнопка выхода возвращает на `/login`, после неё оповещения не приходят.

## Что проверено автоматически

Перед выкладкой интерфейс был прогнан в настоящем браузере (Chromium) против имитации сервера, повторяющей контракт backend: 37 проверок по пунктам выше. Имитация проверяет, что клиент правильно обращается к API, но не заменяет проверку с настоящим backend и базой данных.
