# Настройка

Настройки читаются из файла `backend/.env` (шаблон: [`.env.example`](../.env.example)). Файл `.env` содержит секреты и **не попадает в git**.

```bash
cp .env.example .env        # Windows: copy .env.example .env
```

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `DATABASE_URL` | да | нет | Подключение к MySQL: `mysql+pymysql://пользователь:пароль@хост:порт/база` |
| `SECRET_KEY` | да | запасное значение в коде, см. [security.md](security.md) | Ключ подписи JWT. Сгенерировать: `python -c "import secrets; print(secrets.token_hex(32))"` |
| `ALGORITHM` | нет | `HS256` | Алгоритм подписи JWT |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | нет | `30` | Срок жизни токена доступа |
| `DETECTION_INTERVAL_SECONDS` | нет | `60` | Как часто симулятор «видит» автомобиль, см. [simulator.md](simulator.md) |
| `SMTP_USER` | нет | пусто | Почта-отправитель оповещений |
| `SMTP_PASSWORD` | нет | пусто | Пароль приложения (для Gmail это не пароль от аккаунта) |
| `SMTP_SERVER`, `SMTP_PORT` | нет | по домену `SMTP_USER` | Почтовый сервер и порт. Нужны для сервисов, кроме Gmail и Яндекс |
| `SEED_USERS_FILE` | нет | `seed_users.json` | Путь к файлу с тестовыми сотрудниками для `seed.py` |

Срок жизни токена для скачивания отчёта (2 минуты) задан в коде (`EXPORT_TOKEN_MINUTES` в `routes/alerts.py`).

## Почта

Письмо об оповещении отправляется, только если заполнены `SMTP_USER` и `SMTP_PASSWORD`. Иначе в консоль выводится предупреждение, остальное работает.

Если `SMTP_SERVER` и `SMTP_PORT` не заданы, сервер выбирается по домену отправителя:

| Домен `SMTP_USER` | Сервер | Порт | Соединение |
|---|---|---|---|
| `gmail.com` | `smtp.gmail.com` | 587 | STARTTLS |
| `yandex.ru`, `ya.ru` | `smtp.yandex.ru` | 465 | SSL |
| любой другой | `smtp.yandex.ru` | 465 | SSL |

Если порт явно задан, `587` означает STARTTLS, любой другой порт означает SSL-соединение.

## Тестовые данные: `seed.py` и `seed_users.json`

`python seed.py` создаёт таблицы и заполняет справочники: подразделение, категории нарушений, 15 камер, автомобили. Также создаются тестовые сотрудники. **Их логины и пароли лежат в JSON-файле, а не в коде.**

1. Создайте файл из шаблона (один раз):

   ```bash
   cp seed_users.example.json seed_users.json     # Windows: copy seed_users.example.json seed_users.json
   ```

2. При желании отредактируйте логины и пароли. Формат:

   ```json
   {
     "employees": [
       {
         "login": "ivanov_ai",
         "password": "ВАШ_ПАРОЛЬ",
         "full_name": "Иванов Алексей Игоревич",
         "position": "Инспектор ДПС",
         "email": "ivanov@gibdd-kirov.example"
       }
     ]
   }
   ```

   Все пять полей обязательны, логины не должны повторяться. Ключ `_comment` загрузчик игнорирует.

3. Запустите `python seed.py`. Если файла нет или он заполнен неверно, скрипт остановится с понятным сообщением и подсказкой.

Что важно:
- `seed_users.json` перечислен в `.gitignore` и в репозиторий не попадает, в git лежит только шаблон `seed_users.example.json`.
- Другой путь можно задать через `SEED_USERS_FILE`, относительный путь отсчитывается от папки `backend`.
- `seed.py` можно запускать повторно: уже существующие записи не дублируются, пароль существующего сотрудника при этом **не** обновляется.
- В консоль выводятся логины, пароли `seed.py` не печатает.
- Проверка загрузчика: `python -m unittest discover -s tests -v` в папке `backend`.
